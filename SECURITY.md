# Vulnerability reporting

If you find a vulnerability in **Польский вслух**, please use GitHub's private
vulnerability reporting feature if available: open the repository's **Security**
tab and select **Report a vulnerability**.

If private reporting is unavailable, contact the repository owner privately.
Do not post proof-of-concept payloads, credentials, session tokens or personal
documents in a public issue.

The public GitHub Pages website has no server-side authentication. A local
profile does not request passwords for VK, Google, or YouTube.

Please include the page/URL, browser, reproduction steps, expected and actual
behaviour, and a minimally sensitive test case.

For compromised credentials, revoke or rotate them in the issuing service.
Do not commit replacement secrets into this repository.
