# Польский вслух — обновлённая образовательная платформа

**Новый интерфейс:** `index.html`, `site.css`, `site.js`. Существующие старые HTML-страницы и аудиоматериалы сохранены.

## Запуск

Это статический сайт для GitHub Pages. В настройках репозитория **Settings → Pages** укажите Deploy from branch → `master` → `/(root)`. Локально откройте через `python -m http.server 8000`, затем http://localhost:8000/.

## Автоматическая синхронизация YouTube

`.github/workflows/sync-youtube.yml` запускается **каждый час** (по расписанию GitHub Actions возможны задержки), а также вручную через Actions → Sync YouTube lessons → Run workflow. Скрипт обновляет `data/videos.json`.

- **Рекомендуется:** GitHub repository secret `YOUTUBE_API_KEY` с ключом YouTube Data API v3. Тогда импортируется весь публичный архив загрузок канала, пагинацией по 50 видео, включая метаданные и длительность.
- **Без ключа:** применяется официальный публичный YouTube RSS, который отдаёт только последние ~15 публикаций. История накапливается по мере обновлений, но старые видео не импортируются автоматически; их можно получить после добавления API-ключа.
- Скрипт не загружает авторское видео/аудио или субтитры, отображает карточки с превью и воспроизводит через официальное встраивание YouTube.
- Если источник недоступен, workflow завершится с ошибкой и **не сотрёт** уже сохранённый каталог.
- Workflow на ветке `master` начнёт работать **после объединения PR**. Первый запуск надо выполнить вручную для немедленного заполнения.

## Что изменилось

Адаптивный дизайн, боковое меню, каталог с поиском и сортировкой, категории A1/A2/песни/диалоги, просмотр через YouTube, избранное в localStorage, автоматическое обновление метаданных.

## Ограничения

Классификация по названиям автоматическая и может требовать ручных уточнений; полные транскрипты YouTube API не предоставляет публично без соответствующего разрешения. Каталог обновляется периодически, не мгновенно. Для корректной работы воспроизведения нужно разрешить YouTube iframe в браузере.
