Безопасность и ваши данные

Этот раздел описывает текущую работу учебного сайта, размещённого на GitHub Pages. Он не является независимым сертификатом безопасности.

Нужен ли пароль от социальной сети?

Нет. Локальный профиль сайта использует никнейм, а не пароль VK, Google или YouTube. Учебный сайт не должен запрашивать коды подтверждения или пароли этих сервисов. Если такая просьба появится, не вводите данные и сообщите владельцу репозитория.

Что происходит с презентациями и прогрессом?

Загруженные PPTX, PDF и TXT обрабатываются JavaScript в браузере пользователя. Извлечённый текст, упражнения и прогресс сохраняются в локальном хранилище этого браузера (localStorage), а не в учётной записи на нашем сервере. Очистка данных браузера может удалить их.

Какие внешние сервисы используются?

  • YouTube: встроенное видео, обложки и переходы на видеохостинг. Сервис может получать стандартные данные сетевого запроса.
  • CDN: на странице импорта подключаются JSZip и PDF.js для чтения файлов, а на некоторых страницах — шрифты Google. При загрузке ресурсов соответствующие провайдеры получают данные сетевого обращения.
  • GitHub Pages: размещение публичных файлов сайта по HTTPS.

Не загружайте презентации из непроверенных источников. Сайт предназначен для учебных материалов.

Если VK пометил ссылку опасной

Не вводите пароль или коды VK на сторонних страницах. Если предупреждение возникло при переходе на сайт, сохраните точный адрес и скриншот уведомления, затем обратитесь в официальную поддержку VK для проверки возможной ошибочной блокировки.

Исходный код доступен в публичном репозитории GitHub. О найденных проблемах безопасности можно сообщить владельцу через репозиторий, не публикуя секреты и персональные данные.
